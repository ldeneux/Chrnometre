# Chronomètre Natation Offline PWA (Vercel)

Cette application Web PWA autonome est conçue pour les entraîneurs et chronométreurs au bord du bassin. Elle calcule automatiquement le nombre de clics requis (ex: 50m / 25m = 2 clics) et enregistre les temps intermédiaires ainsi que le temps final hors-ligne.

## 🚀 Déploiement rapide sur Vercel

1. Extrayez ce fichier ZIP dans votre dossier de travail.
2. Initialisez un dépôt Git et publiez-le sur GitHub :
   ```bash
   git init
   git add .
   git commit -m "Initial commit with new logo"
   ```
3. Rendez-vous sur [Vercel](https://vercel.com) et importez le projet.
4. Cliquez sur **Deploy** ! Aucune variable d'environnement n'est requise.

## 📱 Utilisation Hors-Ligne (PWA)

Une fois déployée sur Vercel :
- Ouvrez le lien sur votre smartphone.
- Cliquez sur **"Ajouter à l'écran d'accueil"**.
- L'application fonctionne sans aucune connexion internet (100% Offline).
